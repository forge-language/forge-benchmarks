# Generic Mersenne recurrence loop versioning

Compiler implementation 5481e3a, with additional predicate-rejection test e7900dc. The native backend recognizes an ordinary scalar while with exactly value=(value*C+K)%M and a sole proven unit index update; it does not use benchmark/function names. Existing type/import/scoping machinery and bounded increment proof remain in force. M=2^k-1 (2<=k<=63), 1<=C<M, 0<=K<M and static (M-1)*C+K<=INT64_MAX are required.

The original side-effect-free loop predicate is evaluated first. If true and 0<=value<M, all updates use exact unsigned product, one Mersenne fold/correction, the same value assignment and the same index step. The result stays in [0,M), so the range guard is checked only on entry. If a guard fails, the original loop executes. Index/bound mutations, calls, extra statements, shared/coroutine storage, nonunit steps and unknown/unsafe closed ranges are rejected. No allocation, public API or JavaScript behavior changes.

The new independent oracle checks 88 seed/dimension/function combinations, including INT64_MIN/MAX, negative and zero bounds, positive recurrence and affine recurrence, at -O0/-O3 with UBSan and JavaScript. Matcher regressions cover rejected shapes, generated-name collisions and the empty-loop predicate ordering. All 22 required suites passed across the full run/rechecked compiler suite; the initial invalid-fixture failure is retained in the [OMO review and verification note](mersenne-loop-omo-review-2026-10-13.md).

The previous explicit generated-C guard hoisting gained about 1.87–1.89× old Forge and reached 1.62–1.65× Rust on virtual Apple M1; that is screening evidence, not proof for this new compiler emitter. Unchanged native compiler verification [run 38349470617](https://github.com/forge-language/forge-benchmarks/actions/runs/38349470617) completed successfully against original 9f70e9d. The [actual native results](mersenne-loop-cross-os-2026-10-13.md) show about 1.84× old Forge and 1.60× Rust on macOS LCG, with near-zero LCG change on Linux/Windows.

A local smoke attempt was rejected before measurement by the clean-source gate because tracked report files were being updated. Its accidentally selected frozen compiler/source-root pairing was also corrected before retry. No performance claim uses that failed attempt. The retry uses the known matching original compiler 9f70e9d and its detached source root, with fresh build/output paths.
